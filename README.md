### Projetos Selecionados

> **01. Catálogo Web & Análise Estatística (Extensão Universitária)**  
> Levantamento de requisitos, modelagem de banco em nuvem e aplicação web em produção com **Python, Streamlit e Supabase** para gestão de catálogo e análise estatística de atendimentos comerciais.  
> 🔗 [Acessar aplicação](https://catalogo-isabelle.streamlit.app) · [Ver código](https://github.com/renisantss/Trabalho-extens-o)

> **02. Dashboard Performance Financeira**  
> Painel executivo em **Power BI** estruturado em Star Schema, aplicando medidas DAX de inteligência de tempo (`DATESYTD`, `SAMEPERIODLASTYEAR`), médias móveis, *Drill Down/Through*, *Bookmarks* e design orientado à usabilidade.

> **03. Sistema de Vendas Desktop (Arquitetura Modular)**  
> Aplicação em **Python** estruturada em camadas (`main`, `validacoes`, `utilitarios`) com `namedtuple` para registros imutáveis, cache via chaves compostas, persistência JSON, relatórios funcionais (`map`/`filter`/`reduce`), testes automatizados (`assert`) e empacotamento `.exe`.

> **04. Mapa de Métricas Integrado**  
> Sistema de análise temporal e estruturas de dados em **Python** com persistência em CSV/JSON, estatística descritiva e visualizações analíticas via Matplotlib.
