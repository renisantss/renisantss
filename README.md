### Projetos Selecionados

> **01. Catálogo Web & Análise Estatística (Extensão Universitária)**  
> Aplicação em produção desenvolvida com **Python, Streamlit e Supabase** para gestão de catálogo e análise estatística de atendimentos comerciais.  
> 🔗 [Acessar aplicação](https://catalogo-isabelle.streamlit.app) · [Ver código](https://github.com/renisantss/Trabalho-extens-o)

> **02. Dashboard Performance Financeira**  
> Painel executivo em **Power BI** estruturado em Star Schema, com medidas DAX de inteligência de tempo (`DATESYTD`, `SAMEPERIODLASTYEAR`), drill-down e tooltips dinâmicos.

> **03. Sistema de Vendas Desktop**  
> Software modularizado em **Python** para cadastro de clientes e controle de vendas, empacotado como executável independente (`.exe`) via PyInstaller.

> **04. Mapa de Métricas Integrado**  
> Sistema de análise temporal e estruturas de dados em **Python** com persistência em CSV/JSON e gráficos analíticos via Matplotlib.
